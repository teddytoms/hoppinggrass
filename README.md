# Hopping Grass

The home page for hoppinggrass.com, an independent game studio.

- `index.html`, `style.css`: the home page.
- `food-make/`: a copy of the Food Make game, made by `./sync-food-make.sh`.
- `chuk-chuk/`: a copy of the Chuk Chuk game, made by `./sync-chuk-chuk.sh`.
- `big-adventure/`: a copy of Food Make: The Big Adventure, made by `./sync-big-adventure.sh`.

To update a game on the site, run its sync script, then commit and push.
